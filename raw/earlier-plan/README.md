# dustgame · 먼지 키우기

작은 먼지들이 모여, 이야기가 있는 방을 만들어 갑니다.

**dustgame**은 먼지를 탄생시키고, 쓰다듬어 성장시키며, 나만의 방을 꾸미는 웹 기반 수집·육성 게임입니다. 먼지와 가구, 방에 담긴 이야기를 발견하고 요정과 함께 모험을 떠나 보세요.

> 현재 개발 중인 개인 프로젝트입니다. 아래 내용은 최신 기획을 기준으로 작성했으며, 실제 구현 범위와 수치는 개발 과정에서 변경될 수 있습니다.

## 어떤 게임인가요?

1. 반짝이는 빛을 발견하고 새로운 먼지를 탄생시킵니다.
2. 먼지를 쓰다듬고 키우며 숨겨진 이야기를 엽니다.
3. 먼지들이 만들어 낸 골드로 재료와 가구를 구매하고 방을 발전시킵니다.
4. 먼지를 모험에 보내고, 돌아온 먼지와 함께 수집을 이어 갑니다.

## 주요 기획

### 먼지 탄생과 수집

- 먼지 종류는 **50종**을 목표로 합니다.
- 빛나는 표시를 선택하면 재료 조합 팝업이 열립니다.
- 재료를 조합하면 조합에 맞는 먼지가 태어납니다.
- 재료를 조합하지 않는 경우 랜덤으로 먼지가 태어납니다.
- 발견한 먼지는 도감에서 확인할 수 있도록 구성합니다.

### 성장과 이야기

- 먼지 몸 위에서 마우스 커서를 움직여 쓰다듬습니다.
- 반짝이는 먼지 위 말풍선으로 표시하며, 커서 이동으로 모으는 방식을 적용합니다.
- 먼지가 레벨업할 때마다 이야기를 하나씩 엽니다.
- 먼지마다 개별 이야기를 갖도록 구성합니다.
- 모바일에서는 터치 조작으로 같은 경험을 제공하는 것을 목표로 합니다.

### 보관과 방 배치

- 키우던 먼지를 보관함에 넣고 다시 꺼내 키울 수 있습니다.
- 보관과 꺼내기를 반복해도 기존 성장 기록을 유지하도록 설계합니다.
- 보관함은 하단의 **모은 먼지** 옆 탭에서 접근합니다.
- 먼지와 가구를 길게 누른 뒤 끌어서 위치를 바꿉니다.
- 방 종류에 따라 먼지 수용 한도를 다르게 설정합니다.

### 골드와 가구

- 먼지는 각자의 생산 주기에 따라 골드를 만듭니다.
- 골드로 방을 업그레이드하고 가구와 재료를 구매하는 구조입니다.
- 가구 종류는 **10종**, 업그레이드는 **5단계**를 목표로 합니다.
- 가구는 먼지 육성과 골드 생산 등을 돕는 효과를 가집니다.
- 가구가 성장하면 외형이 조금씩 달라집니다.
- 방 안에서는 가구 레벨 숫자를 표시하지 않는 방향입니다.
- 가구별 이야기를 발견하며 업그레이드할 수 있도록 구성합니다.

### 방 성장

- 정사각형 방을 기본으로, 먼지와 가구를 배치할 공간을 확보합니다.
- 방 목록에서 업그레이드할 수 있는 방을 확인합니다.
- 방마다 수용 한도와 고유한 이야기를 부여합니다.
- 방 이름과 효과, 골드 상태를 방 내부에서 확인할 수 있도록 구성합니다.

## 요정 친구들

| 캐릭터 | 역할 | 주요 상호작용 |
| --- | --- | --- |
| **루미** | 모험 관리인 | 먼지를 앞으로 끌어다 놓아 모험을 보내고, 루미를 선택해 모험 현황 확인 |
| **모아** | 골드 수령을 돕는 요정 | 상점에서 골드로 구매한 뒤 골드를 일괄 수령하는 기능 제공 |

루미와 모아는 역할을 알아보기 쉽도록 서로 다른 디자인으로 표현합니다.

### 모험

- 루미 앞으로 먼지를 끌어다 놓으면 모험을 떠납니다.
- 루미를 선택하면 모험 중인 먼지, 남은 시간, 귀환 보상을 확인합니다.
- 모험 시간, 파견 조건, 보상 수치는 게임 밸런스에 맞춰 조정합니다.

## 저장과 배포 계획

- **1차 공개:** GitHub Pages를 통한 웹 게임 배포
- **플레이 기록:** 사용자 브라우저에 저장하는 방식으로 시작할 계획
- **향후 확장:** 모바일 조작과 게임 완성도를 다듬은 뒤 Android 앱 및 Google Play 출시 검토

## GitHub Pages에 올리기

빌드가 완료된 정적 배포 파일을 기준으로 진행합니다.

1. 배포 폴더의 `index.html`과 필요한 이미지·CSS·JavaScript 파일을 저장소 최상위에 업로드합니다.
2. 저장소의 **Settings → Pages**로 이동합니다.
3. **Source**에서 **Deploy from a branch**를 선택합니다.
4. 배포 파일이 있는 브랜치(예: `main`)와 **/(root)**를 선택하고 저장합니다.
5. 배포가 완료되면 Pages에 표시된 주소로 접속해 확인합니다.

프로젝트 경로는 `/dustgame/`입니다. 이미지와 스크립트 경로가 해당 경로에서도 동작하도록 설정해야 합니다. 별도 빌드가 필요한 프로젝트라면 소스 파일 대신 빌드 결과물을 업로드합니다.
