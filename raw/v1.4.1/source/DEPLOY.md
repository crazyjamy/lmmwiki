# GitHub Pages에 올리기

배포 주소: https://crazyjamy.github.io/dustgame/
저장소: https://github.com/crazyjamy/dustgame

1. ZIP을 압축 해제해요.
2. 저장소의 **Add file → Upload files**를 눌러요. 압축을 푼 폴더 안의 파일을 모두 올려요. ZIP 자체나 바깥 폴더를 올리지 않아요.
3. 저장소 첫 화면에 `index.html`, `dust.mjs`, `dust.css`, 나머지 `.mjs` 파일이 함께 보여야 해요. 같은 이름의 기존 파일은 교체돼요.
4. 커밋 문구는 `방 성장 보상 연결 및 모바일 팝업·희귀 먼지 효과 개선`처럼 적고 main 브랜치에 커밋해요.
5. Pages가 이미 main / (root)로 설정돼 있으면 추가 설정은 필요 없어요. 처음이라면 **Settings → Pages → Deploy from a branch → main → /(root) → Save**를 선택해요.
6. Actions에서 배포 완료를 확인한 뒤 게임 주소를 열어요. 이전 화면이 보이면 Mac은 Cmd+Shift+R, Windows는 Ctrl+Shift+R로 새로고침해요.

배포 파일에는 빌드·설치가 필요 없어요. 이미지·아이콘은 대부분 코드 안의 SVG이며 파일 경로는 `/dustgame/` 아래에서도 동작하도록 상대 경로를 사용해요. 글꼴을 내려받을 수 없는 환경에서는 기본 글꼴로 표시돼요. 이 버전에는 새 파일을 구분하는 버전 표시가 포함돼요.

## 기록을 유지하려면

- 업데이트 전 게임의 작은 기록에서 JSON을 한 번 내보내 보관하는 것을 권해요.
- 같은 브라우저에서 같은 `https://crazyjamy.github.io/dustgame/` 주소를 쓰면 기존 자동 저장 기록을 이어가요.
- 테스트 사이트의 기록은 GitHub 주소로 자동 이동하지 않아요. 테스트 사이트에서 내보낸 뒤 GitHub 게임에서 불러와주세요.
- 다른 브라우저·기기나 다른 저장소 주소로 옮길 때도 내보내기와 불러오기를 사용해요.
- 저장 파일 불러오기는 미리보기 후 확인해야 적용돼요. 잘못된 파일이나 지원하지 않는 형식은 현재 기록을 바꾸지 않아요.

`.nojekyll`은 빈 파일이에요. 파일이 보이지 않는 환경에서도 나머지 파일은 정상적으로 사용할 수 있어요. 이전 게임의 무관한 파일을 삭제할 필요는 없지만, 이번 ZIP 안의 파일은 빠짐없이 함께 교체해주세요.
