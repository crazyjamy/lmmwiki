# 별 키우기 아이콘 디자인 가이드

적용 버전 v1.13.21 · 2026-11-20

## 기본 규격

- UI 아이콘은 24 × 24 SVG 그리드에 그립니다. 일반 도형은 좌우·상하 약 2~3 단위의 여백을 두고, 한 줄로 읽히는 실루엣을 우선합니다.
- 선 굵기는 1.6, 끝과 모서리는 round를 사용합니다. 기본은 외곽선이며 골드처럼 기능을 구분할 때 내부 일부만 채웁니다.
- 실제 표시 크기는 16px 보조 정보, 20px 일반 동작, 24px 하단 메뉴를 기준으로 합니다. 아이콘 크기와 조작 영역은 별개입니다. 모바일 주요 조작의 터치 영역은 44px 이상을 목표로 하고, 좁은 영역에서도 인접 동작과 구분될 여백을 둡니다.
- 일반 아이콘은 글자색을 상속합니다. 골드는 금색 토큰, 반짝이는 하늘색 토큰을 사용합니다. 선택 상태는 기존 버튼 배경과 텍스트 상태를 함께 사용합니다.
- 캐릭터, 설치물, 조합 재료, 획득 가능한 반짝이 등은 게임 속 일러스트입니다. 형태와 색으로 식별할 수 있도록 각자의 일러스트를 사용합니다.

## 의미와 사용 위치

| 의미 | 형태 | 사용하는 곳 |
|---|---|---|
| 은하계 홈·거주 수 | 지붕과 문이 있는 집 | 하단 메뉴, 상단 거주 수 |
| 모은 별·도감 | 둥근 2×2 격자 | 하단 메뉴, 상단 발견 수, 모은 별 탭 |
| 보관함·별 보관 | 뚜껑과 손잡이가 있는 상자 | 하단 메뉴, 별 간단 패널, 빈 보관함 |
| 작은 상점 | 차양이 있는 가게 | 하단 메뉴 |
| 생활 수첩 | 책등이 있는 닫힌 수첩 | 상단, 설정 목록, 수첩 빈 화면 |
| 별 이야기 | 펼친 책 | 별 간단 패널, 별 상세보기의 개별 이야기 |
| 별 상세보기 | 글줄이 있는 한 장의 문서 | 별 간단 패널 |
| 조합 기록·모험 엽서·테마 수집 | 플라스크·봉투·네 꼭짓점 별 | 도감 탭 |
| 골드·반짝이 | 원형 동전·네 꼭짓점 별 | 상단과 재화 표시 |
| 배치·탐사 구역·행성 기록 | 양방향 화살표·조준점·고리 행성 | 홈 조작부 |
| 설정·별명 짓기·별 합치기 | 슬라이더·연필·두 원과 더하기 | 상단, 별 패널 |
| 완료·닫기·잠김 | 체크·X·자물쇠 | 상태와 팝업 |

## 구현 기준

- 공용 SVG는 `dist/ui-icons.mjs`의 `uiIcon()`에서 관리합니다. 템플릿에서 `uiIcon('storage')`처럼 호출하고, 고정 HTML은 `data-ui-icon="storage"`로 같은 원본을 참조합니다.
- 버튼에 글자와 아이콘이 함께 있으면 아이콘을 보조로 둡니다. 좁은 화면에서 글자를 숨기는 경우에도 버튼의 접근 가능한 이름을 유지합니다. SVG 자체는 보조기기에서 숨깁니다.
- 같은 동작의 아이콘이 필요하면 표의 기존 이름을 우선 검색합니다. 간격, 정렬, 크기는 CSS로 조정해 SVG 원본을 복제하지 않습니다.
- 추가하거나 바꾼 뒤에는 모바일과 PC에서 모양, 포커스, 텍스트 잘림, 같은 동작의 아이콘 일치 여부를 확인합니다.

## 가구와 제작 재료 · 2026-11-25

가구와 재료는 52 × 52 그리드에 그립니다. 가구는 보라색 외곽선(#7761a0, 1.65), 재료는 회보라색 외곽선(#716281, 1.6)을 사용합니다. 선 끝과 모서리를 둥글게 하고 색면과 실루엣으로 종류를 구분합니다.

| 재료 | 재료의 특징 | 제작 가구 | 가구의 특징 |
|---|---|---|---|
| 나뭇가지 | 잎이 달린 갈색 갈래 | 나무 스툴 | 둥근 좌판과 짧은 다리 |
| 빛조개 | 청록색 부채꼴과 방사형 골 | 조개 조명 | 펼친 분홍 조개와 따뜻한 진주등 |
| 달빛석 | 연보라색 결정과 각진 단면 | 달빛 선반 | 납작한 돌 선반과 금빛 초승달 |

- 상점·보관함·은하계·가구 팝업은 같은 가구 원화를 사용합니다. 보유 가구는 레벨에 따라 원화 아래에 성장 점을 표시합니다.
- 제작 도안은 기존 가구 카드의 그림 영역, 상태, 이름, 제작 재료, 행동 버튼 순서를 따릅니다. 잠긴 도안에는 해금 단서를 함께 표시합니다.
- 재료 상점 카드는 조합 재료와 같은 그림 크기와 여백을 사용합니다. 도안 안에서는 같은 그림을 24px로 줄이고 이름과 ‘보유 수량 / 필요 수량’을 함께 표시합니다. 도안을 발견하고 모든 재료가 충분하면 제작 버튼을 활성화합니다.
