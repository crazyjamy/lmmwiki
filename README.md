## 자료를 추가할 때

자료를 주고 **“먼지 위키에 반영하고 깃허브에도 올려줘”**라고 요청합니다.
AI는 관련 기존 문서를 먼저 찾고, 원본을 보존하면서 문서·목차·변경 기록을 갱신합니다.

질문이나 아이디어 상담만으로 문서를 바꾸지 않습니다. 대화 밖에서 자동으로 저장소를 감시하거나 갱신하는 작업은 설정하지 않았습니다.

## 문서를 읽는 기준

- **확정:** 사용자의 명시적인 결정·승인 근거가 있는 내용
- **코드 확인:** 제공된 버전에서 구현 근거를 찾은 내용. 실제 플레이 검증과는 구분합니다.
- **변경 요청 / 검토 중:** 요청이나 제안이 있으며 적용·승인은 별도로 확인할 내용
- **미확인:** 자료가 없거나 실제 동작·현재 배포 상태를 확인하지 못한 내용
- **AI 해석:** 자료를 연결해 정리한 설명이며 승인된 기획으로 취급하지 않는 내용

게임 코드 저장소는 [crazyjamy/dustgame](https://github.com/crazyjamy/dustgame), 이 위키 저장소는 [crazyjamy/lmmwiki](https://github.com/crazyjamy/lmmwiki)입니다.
