먼지가 흘리는 하루 반짝이 · v1.4.1

항목 v1.4.1에서 확인한 규칙
하루 기준 한국 시간 자정(UTC+9)
대상 방에 있으며 보관·모험 중이 아닌 먼지
수량 먼지 한 마리당 반짝이 1개
획득 행동 바닥의 별을 선택해 수령
새 먼지 태어난 날의 날짜를 기록하여 다음 날부터 생성
기존 기록 날짜 필드가 없는 먼지는 초기화 시 전날로 설정하여 첫 방문에 생성 가능
미수령 누적 먼지 식별자별 최대 1개. 여러 날 치를 누적하지 않음
늦게 수령한 날 해당 먼지가 남아 있으면 그날 새 반짝이를 다시 만들지 않도록 날짜 갱신
이동·보관·합치기 이미 생성한 반짝이 데이터는 별도로 유지하며 수령 가능
배치 모드 선택 처리에서 수령하지 않음
  • 마지막 두 항목은 화면 처리 코드의 dailySparkle 처리와 함께 확인했습니다.
  • 반짝이는 게임 실행 중 방 렌더링·업데이트에서 생성됩니다. 앱을 닫은 상태에서 별도의 서버가 생성하는 기능으로 기록하지 않습니다.

시간제 모험과 직접 탐험 · v1.4.1

구분 경로 기본 시간 / 진행 방식 보상
시간제 모험 책장 아래 숲 20초, 기본 해금 재료·반짝이 2개
시간제 모험 햇살 창가 45초, 방 Lv.20 재료·반짝이 3개
시간제 모험 달빛 다락길 90초, 방 Lv.70 재료·반짝이 5개
직접 탐험 책상 아래 이동하며 시야 확장, 수집, 지우개 밀기, 출구로 귀환 수집한 재료와 귀환 기록
  • 시간제 모험은 바람 종의 효과로 시간을 줄일 수 있습니다.
  • 기존 저장 데이터에서 이미 열린 경로는 유지할 수 있습니다.
  • 직접 탐험의 ‘책상 아래’와 시간제 경로 ‘책장 아래 숲’은 서로 다른 기능입니다.
  • 직접 탐험은 솜뭉치·풀잎·이슬방울을 찾고 숨은 길을 여는 구조이며, 중단 후 이어가기 데이터가 있습니다.
  • 이 경험이 충분히 재미있는지는 코드만으로 판단하지 않습니다.
