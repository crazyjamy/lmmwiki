**설치물 얻는 방법 (v1.13.25~)**

1. 첫 별의 이야기를 읽으면 **행성 고리**를 받습니다.
2. 이후 별 발견·모험·은하계 성장 등 설치물마다 정해진 조건을 별빛 임무에서 확인합니다.
3. 받은 설치물은 작은 상점에서 배치하고 골드로 강화합니다.

근거: [자료 S19](sources.md), [배포 이력](release-history.md)

### 별과 설치물에 남는 기억 · v1.13.33 이후

- 첫 본편을 읽은 별은 좋아하는 설치물 **Lv.1** 곁에서도 자리 후일담을 발견합니다.
- 기존 Lv.3 설치물 기억과 별개이며, 둘 다 ‘함께 쓴 이야기’에서 읽을 수 있습니다.
- 후일담을 읽은 뒤에는 해당 자리의 대사가 달라집니다.
- 본편 해금이나 설치물 강화의 필수 조건은 아닙니다.

[별의 이야기와 기록](dust-growth.md), [변경 내용](../raw/v1.13.35/RELEASE-NOTES.md)

## 방 성장 · v1.4.1

| 항목 | v1.4.1 코드에서 확인한 내용 |
| --- | --- |
| 레벨 | Lv.1~100 |
| 수용 한도 | 방 레벨 × 2마리: 2마리에서 최대 200마리 |
| 확장 비용 | 반짝이 사용. 다음 레벨의 cost 차감 |
| 10레벨 단위 | 방 이야기와 보상 장식 |
| Lv.20 | 햇살 창가 시간제 모험 해금 |
| Lv.30 | 한국 시간 기준 하루 한 번 손님에게 정수 1개 수령 |
| Lv.70 | 달빛 다락길 시간제 모험 해금 |
| Lv.100 | 마지막 방 이야기와 귀가의 은하수 장식 |

이전 저장 데이터에서는 기존 방 보너스·보관함 용량·열린 모험 경로를 보존하는 로직이 있습니다. 새 기록과 이전 기록의 표시가 완전히 같다고 단정하지 않습니다.

## 가구 10종 · 최대 5단계 · v1.4.1

구매·업그레이드는 골드를 사용합니다. 아래는 **배치한 가구**의 효과이며, L은 해당 가구 레벨(1~5)입니다.

| 가구 | 구매 골드 | 배치 효과 |
| --- | ---: | --- |
| 폭신한 러그 | 60 | 합치기 성공 시 반짝이 +L |
| 작은 화분 | 80 | 쓰다듬기 성공 보상에 반짝이 +L |
| 달빛 조명 | 100 | 골드 생산 간격 20~40% 감소 |
| 구름 쿠션 | 120 | 골드 보상 배율에 25~65% 추가 |
| 이야기 책장 | 90 | 먼지의 각 이야기 최초 읽기 시 반짝이 +L |
| 따뜻한 찻잔 | 70 | 쓰다듬기 간격 L × 50ms 감소 |
| 모험 바구니 | 110 | 모험·책상 아래 탐험의 정수 보상 항목마다 +L |
| 바람 종 | 100 | 시간제 모험 소요 시간 L × 5% 감소 |
| 별 모래시계 | 130 | 먼지의 골드 수령 한 생산 회분 보상에 L × 2 추가 |
| 작은 오르골 | 160 | 먼지 한 마리의 골드 수령 성공 시 반짝이 +L |

- 업그레이드 비용은 Lv.1→2부터 차례로 40 / 80 / 140 / 220골드입니다.
- 보유 레벨의 허용 범위와 업그레이드 상한은 코드에서 1~5로 제한합니다.
- 가구 효과가 **하루 바닥 반짝이 수량을 늘리는 로직**은 v1.4.1의 daily-sparkles.mjs에서 확인되지 않습니다.

- [성장 코드](../raw/v1.4.1/source/dust-engine.mjs): pet, mergeDust, readStory
