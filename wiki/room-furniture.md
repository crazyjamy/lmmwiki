## 현재 배포본 · 설치물과 자유 배치

v1.13.25부터 설치물 20종은 **별빛 임무**의 보상입니다. 첫 별의 이야기를 읽으면 행성 고리를 받습니다. 이후 별 발견·모험·은하계 성장 등 각 설치물의 조건을 확인할 수 있습니다. 받은 설치물은 작은 상점에서 배치하고 골드로 강화합니다. [자료 S19](sources.md)

v1.13.12에서 별과 장비는 행성 지평선 위쪽에도 배치할 수 있습니다. 배치한 별과 장비 및 그 위치에 생성된 반짝이는 새로고침 뒤에도 지평선 위에 남는지 소스 테스트에서 확인했습니다. [배포 이력](release-history.md)

v1.13.22부터 성장 지도는 **별빛 임무 → 은하계 진행도**에 있습니다. v1.13.24부터 상단의 사용 중인 은하계 자리에는 탐험 중인 별이 돌아올 자리도 포함합니다. [배포 이력](release-history.md)

### 가구 20종과 최대 Lv.10의 이전 규칙

v1.5.0에서 구매 가구를 20종, 최대 Lv.10으로 확장했습니다. v1.9.4 코드의 가구 목록과 레벨 상한에서도 같은 규모를 확인했습니다. 가구 구매·강화는 골드를 쓰며, 배치한 가구에 효과가 적용됩니다.

은하계 전환 이후에는 러그가 **행성 고리**, 작은 화분이 **미세중력 온실**, 달빛 조명이 **항법 비콘**, 구름 쿠션이 **달 착륙 포드**로 표시됩니다. 강화 비용은 Lv.2부터 차례대로 40 / 80 / 140 / 220 / 320 / 450 / 600 / 800 / 1,050 골드입니다. 근거는 [자료 목록 S5~S6](sources.md)과 [배포 이력](release-history.md)에 있습니다.

## 방 성장

| 항목 | v1.4.1 코드에서 확인한 내용 |
| --- | --- |
| 레벨 | Lv.1~100 |
| 수용 한도 | 방 레벨 × 2마리: 2마리에서 최대 200마리 |
| 확장 비용 | 반짝이 사용. 다음 레벨의 cost 차감 |
| 10레벨 단위 | 방 이야기와 보상 장식 |
| Lv.20 | 햇살 창가 시간제 모험 해금 |
| Lv.30 | 한국 시간 기준 하루 한 번 손님에게 정수 1개 수령 |
| Lv.70 | 달빛 다락길 시간제 모험 해금 |
| Lv.100 | 마지막 방 이야기와 귀가의 은하수 장식 |

이전 저장 데이터에서는 기존 방 보너스·보관함 용량·열린 모험 경로를 보존하는 로직이 있습니다. 새 기록과 이전 기록의 표시가 완전히 같다고 단정하지 않습니다.

## 가구 10종 · 최대 5단계

구매·업그레이드는 골드를 사용합니다. 아래는 **배치한 가구**의 효과입니다.
L은 해당 가구 레벨(1~5)입니다.

| 가구 | 구매 골드 | 배치 효과 |
| --- | ---: | --- |
| 폭신한 러그 | 60 | 합치기 성공 시 반짝이 +L |
| 작은 화분 | 80 | 쓰다듬기 성공 보상에 반짝이 +L |
| 달빛 조명 | 100 | 골드 생산 간격 20~40% 감소 |
| 구름 쿠션 | 120 | 골드 보상 배율에 25~65% 추가 |
| 이야기 책장 | 90 | 먼지의 각 이야기 최초 읽기 시 반짝이 +L |
| 따뜻한 찻잔 | 70 | 쓰다듬기 간격 L × 50ms 감소 |
| 모험 바구니 | 110 | 모험·책상 아래 탐험의 정수 보상 항목마다 +L |
| 바람 종 | 100 | 시간제 모험 소요 시간 L × 5% 감소 |
| 별 모래시계 | 130 | 먼지의 골드 수령 한 생산 회분 보상에 L × 2 추가 |
| 작은 오르골 | 160 | 먼지 한 마리의 골드 수령 성공 시 반짝이 +L |

효과 적용 근거: 가구 코드의 activeLevel, lampFactor, cushionBonus,
[성장 코드](../raw/v1.4.1/source/dust-engine.mjs)의 pet·mergeDust·readStory,
재화 코드의 goldAmount·collectGold,
[모험 코드](../raw/v1.4.1/source/adventures.mjs)의 startAdventure·claimAdventure,
[탐험 코드](../raw/v1.4.1/source/desk-exploration.mjs)의 finishDesk.

업그레이드 비용은 Lv.1→2부터 차례로 40 / 80 / 140 / 220골드입니다.
보유 레벨의 허용 범위와 업그레이드 상한은 코드에서 1~5로 제한합니다.
가구 효과가 **하루 바닥 반짝이 수량을 늘리는 로직**은 v1.4.1의 daily-sparkles.mjs에서 확인되지 않습니다.
