## 개발 변경의 테스트·공개 절차

2026-11-26 프로젝트 담당자의 개발 위키 반영 요청으로 확정했다.

1. 작업 전 위키 목차와 변경 기록에서 최신 확정 정책을 찾는다. 지난 작업 이후 바뀐 정책과 영향을 받는 화면을 프로젝트 담당자에게 먼저 알린다.
2. 변경은 비공개 테스트 사이트에 먼저 배포한다. 일반 테스트에서는 플레이어가 사용하는 진입 버튼부터 따라가 안내 문구, 튜토리얼, 해금과 보상을 확인한다.
3. 원하는 별이 없거나 긴 대기·최초 수령 때문에 재현이 어려우면 DEV의 장면 선택과 다시 시작을 사용한다. 이야기 연출은 미리보기로, 해금은 합치기 직전부터 직접 조작해 검증한다. 필요한 장면이 없으면 해당 변경을 재현하는 장면을 추가한다.
4. 저장·보상이 바뀌면 같은 탭을 새로고침해 진행과 수령 여부를 확인한다. DEV에서 보상을 받은 뒤 일반 테스트로 돌아가 기존 별과 재화가 유지되는지도 확인한다.
5. 관련 위키와 변경 기록에 테스트 적용일, 소스 버전, 확인한 플레이 경로와 미확인 범위를 남긴다. 프로젝트 담당자의 명시적인 최종 승인 후 승인된 게임 변경만 공개 저장소와 GitHub Pages에 반영한다. DEV 장면은 테스트 사이트 전용으로 유지하고 공개 배포 결과를 별도로 기록한다.

## 2026-11-26 · 일반 테스트와 DEV 장면

일반 테스트는 기존 은하계를 불러오고, DEV 주소는 장면 선택을 먼저 연다. 일반 기록은 브라우저에, DEV 연습 기록은 해당 탭에 별도로 저장한다. 같은 DEV 탭에서 새로고침하면 진행한 장면이 이어진다.

[DEV 장면 선택](https://little-dragon-nest-hyerin.coursemos-3149.chatgpt.site/?dev=1) · [일반 테스트](https://little-dragon-nest-hyerin.coursemos-3149.chatgpt.site/)

| 장면 | 확인 방법 |
| --- | --- |
| 빈 은하계 | 보유 별 0마리와 모든 별을 보관한 상태를 각각 확인한다. |
| 별 상세 | 50종에서 별과 Lv.1~6을 고른다. 헬리아와 유로파의 두 번째 손길은 바로 열 수 있다. |
| 이야기 미리보기 | 첫인사, 성장 이야기 5편, 후일담 4편을 바로 읽는다. 미리보기는 읽음이나 보상을 기록하지 않는다. |
| 합치기 직전 | 같은 종류 두 별을 준비한다. Lv.1~5 중 고른 별과 Lv.1 별을 직접 합쳐 다음 이야기의 해금과 읽음을 확인한다. |
| 엽서 귀환 | 첫 엽서와 이미 받은 엽서를 각각 준비한다. 귀환 보상 버튼으로 최초 자동 표시와 중복 수령을 확인한다. |

기존 설정의 개발 모드를 별도 주소의 DEV 장면 선택으로 옮겼다. 월간 원고와 엽서 미리보기는 DEV 장면 선택에서 이어서 열 수 있다. 근거는 2026-11-26 프로젝트 담당자의 테스트 사이트 반영 요청과 테스트 소스 `339ab8fc`이다.

## 기록 저장

### 저장 방식

| 항목 | 확인한 내용 |
| --- | --- |
| 저장 위치 | 브라우저 localStorage의 `tiny-dust-club-v1` 키 |
| 기기·브라우저 이동 | JSON 내보내기·불러오기 기능으로 안내 |
| 내보내기 형식 | `tiny-dust-save`, schemaVersion 3 |
| 불러오기 지원 | 해당 형식의 스키마 2·3과 기존 상태 JSON |
| 파일 크기 제한 | UTF-8 기준 5MB 이하 |
| 안전장치 | 불러오기 전 요약 확인, 불러오기·초기화 전 최근 기록 한 개를 복구용으로 보관 |
| 서버 계정 동기화 | 이번 확인 범위에서 구현을 발견하지 못함. 도입 계획은 미확인 |
