## 현재 배포본 · v1.9.4

v1.8.0부터 방은 **은하계**, 수집하는 친구는 **별**로 표현합니다. 핵심 흐름은 친구를 만나고, 같은 종류·레벨끼리 합치고, 이야기와 가구로 공간을 키우는 수집·육성입니다.

최신 코드에서 별 50종, 별 성장 이야기 250편, 은하계 100레벨, 구매 가구 20종과 최대 Lv.10, 시간제 파견 3개 경로와 직접 걷는 **외곽 관측소**를 확인했습니다. 구현과 배포 범위는 [배포 이력](release-history.md)과 [자료 목록](sources.md)을 참고하세요.

## 초기 v1.4.1 자료에서 설명한 게임

작은 먼지를 만나고, 같은 친구를 합쳐 성장시키며, 이야기와 가구로 방을 채워가는 수집·육성 웹 게임입니다.
이는 S2-R의 게임 설명을 정리한 내용입니다.

**위키 주제:** 사용자가 「작고소중한 먼지키우기」를 첫 위키 주제로 지정했습니다. 문서에서는 ZIP 내부 제목을 따라 「작고 소중한 먼지 키우기」로 표기합니다.

## 제공된 버전에서 확인한 규모

| 항목 | v1.4.1 코드 확인 |
| --- | --- |
| 먼지 종류 | 50종 |
| 먼지 레벨 | Lv.1~6, Lv.2~6에서 이야기 해금 |
| 방 | 100레벨, 수용 한도 2~200마리 |
| 구매 가구 | 10종, 최대 Lv.5 |
| 시간제 모험 | 3개 경로 |
| 직접 걷는 탐험 | 책상 아래 |
| 기록 보관 | 브라우저 저장, JSON 내보내기·불러오기 |

개수는 코드 모듈에서 확인했습니다. 세부 근거는 주제별 문서에 연결했습니다.

## 게임 목표

**AI 해석:** ‘새 먼지를 발견하고 이야기를 읽으며 함께 사는 방을 키우는 즐거움’을 중심 경험으로 정리할 수 있습니다.
이 문장은 목표 초안이며, 사용자에게 승인받은 최종 프로젝트 목표는 아닙니다.
장기 목표, 최종 엔딩, 반복 플레이의 우선순위는 [확인이 필요한 사항](open-questions.md)에 남깁니다.
