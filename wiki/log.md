# 변경 기록

## 2026-11-27 · 고양이 개발자 제니

개발 위키의 공개 작성자명을 ‘고양이 개발자 제니’로 정하고, 게임 개요에 제니의 외형과 개발 일지 말투를 기록했다.

## 2026-11-27 · 월간 별자리 이야기의 문장별 빛 효과

디자인 가이드의 문장별 쉬머를 월간 별자리 이야기 본문과 펼친 관측 노트에 적용했다. 본문은 이번 접속에서 편마다 처음 열 때 재생한다. 줄당 2초와 움직임 감소 설정은 공통 이야기 효과를 따른다. 테스트판 222, 소스 `c9675d35`. 거문고자리 첫 편의 실제 애니메이션과 관측 노트, 다음 편에서 이전 편으로 돌아왔을 때의 정적인 본문을 브라우저로 확인했다.


## 2026-11-27 · 첫 만남 카드의 후일담 읽기

프로젝트 담당자의 요청으로 같은 두 별의 첫 만남과 친구 후일담이 동시에 열리면 첫 만남 카드 안에 ‘후일담 읽기’를 표시한다. 새 소식 개수도 카드 한 장으로 센다. 이전 기록에도 같은 기준을 적용한다. 테스트 사이트 버전 221, 소스 `f5d916a6`. 기존 저장 형식과 새 저장 형식에서 후일담 열람과 읽음 상태 복원을 코드로 확인했다.


## 2026-11-27 · 테스트 사이트 생활 수첩

1분 이상 자리를 비운 뒤 수첩을 열면 미확인 부재 기록은 ‘자리를 비운 사이’, 다른 미확인 기록은 ‘새 소식’, 읽은 항목은 ‘이전 기록’에 표시한다. 열람과 함께 읽음 상태를 저장한다. 새 기록에 지급된 작은 부탁·복귀 시 유리병 반짝이가 있으면 최상단에 합계를 표시한다. 기록 속 별과 반짝이는 작은 그림으로 표시하고 복귀 안내·확인 버튼·엽서함 링크는 숨긴다.

근거는 프로젝트 담당자의 생활 수첩 캡처와 변경 요청이다. 테스트 사이트 버전 220, 소스 `41525a5a`. 기존 저장에서 수첩을 열어 이전 부재 기록을 확인했고 자동 검사 174개가 통과했다.


## 2026-11-26 · 가구와 별자리 이야기 검사 수정

가구 이야기 모듈이 다른 주소로 로드돼도 원본 배열을 변경하지 않게 수정했습니다. 별빛 임무 설치물 20종에 각각 이야기 10편이 있는지, 공개판에서 귀환 별빛으로 이야기가 열리는지, DEV 미리보기가 진행 기록을 추가하지 않는지 확인했습니다. 테스트 사이트 소스 d776b641의 자동 검사 174개가 통과했습니다. 프로젝트 담당자의 최종 승인으로 가구 이야기 중복 수정본을 공개 게임에 배포했습니다. 공개판 검사 169개가 통과했고, DEV 전용 미리보기 검사 1개는 제외했습니다. [공개 게임 커밋](https://github.com/crazyjamy/dustgame/commit/468122e878337d486f3d6f762b966a3797c31347)

## 2026-11-26 · 가구 성장·별자리·생활 수첩 공개 반영

프로젝트 담당자의 최종 승인으로 가구 강화 원화와 이야기 화면, 배치 모드의 별 숨김, 별자리 이름과 완성 상태, 탐험 탭, 복귀 생활 수첩을 공개 게임에 반영했습니다. 공개판용 검사 167개 중 164개가 통과했습니다. 가구와 월간 이야기 검사 3개는 배포 전 원본에서도 동일하게 실패했습니다. [공개 게임 커밋](https://github.com/crazyjamy/dustgame/commit/be124c25066edc404bd20bd15619949af27d76dc)

## 2026-11-26 · 가구 성장·별자리·생활 수첩 테스트
