## 2026-11-23 · 별이 머무는 곳 v1.13.35와 이야기·기록 통합

- 명시적 이름 변경 요청에 따라 현행 이름을 **별이 머무는 곳**으로 갱신했습니다. 과거 원본과 이름은 보존했습니다.
- 50종의 연결된 성장 이야기, 루미의 관측 노트, 문장별 쉬머와 플로팅 메뉴, 밑줄형 탭 및 필터 위계를 기록했습니다.
- 플레이 행동의 후일담과 은하계 반응, 별 상세의 ‘함께 쓴 이야기’, 개체별 기록과 종별 공동 엽서의 구분, 선택 단서 하나를 기존 주제 문서에 반영했습니다.
- v1.13.35 패키지 명세·버전 파일·릴리스 노트·검증 결과·요청 발췌를 신규 raw 경로에 추가했습니다. 게임 ZIP과 전체 게임 소스는 공개 위키에 추가하지 않고 사용자에게 다운로드로 제공합니다. 기존 raw 파일은 수정하지 않았습니다.
- 자동 테스트 155개 통과와 Chrome PC·390px 미리보기 확인, 비공개 사이트 v1.13.35 배포 성공을 구분해 기록했습니다.
- 게임 저장소 버전 파일 v1.13.27을 재조회했습니다. 이번 작업에서 게임 저장소 업로드와 GitHub Pages 배포를 수행하지 않았습니다. 위키 문서만 GitHub에 업데이트합니다.
- 목차·자료 목록·로그·저장과 배포·미확인 항목을 함께 갱신했습니다.

## 2026-11-23 · v1.13.25~27 변경 및 배포 패키지

## 2026-11-18 · 초기 구성

- 사용자가 지정한 crazyjamy/lmmwiki 저장소가 비어 있음을 확인했습니다.
- 작고 소중한 먼지 키우기를 위키 주제로 구성했습니다.
- 기존 기획 README와 v1.4.1 ZIP을 원본 그대로 보관하고, ZIP 내부 파일을 변경 없이 풀어 코드 근거로 연결했습니다.
- 이번 사용자 메시지 발췌와 별도 대화 요약에서 전달된 가구 확장 요청을 출처 유형별로 보관했습니다.
- 게임 개요, 먼지 수집·성장, 방·가구, 재화·모험, 저장·배포, 확인할 사항을 작성했습니다.
- 과거 기획과 코드의 성장 방식·재화 사용 차이를 기록했습니다.
- 가구 20종·10단계 확장은 변경 요청으로 남기고 v1.4.1의 10종·5단계와 구분했습니다.
- 목차·자료 목록·위키 관리 규칙을 추가했습니다.
- 원본 체크섬, 압축 해제본의 바이트 일치, 문서 내부 링크, 코드 데이터 개수와 문서 수치를 확인했습니다.
- 브라우저 플레이와 현재 게임 사이트의 배포 상태는 검증하지 않았습니다.
