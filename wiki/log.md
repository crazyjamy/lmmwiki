## 2026-11-20 · v1.13.24까지 배포 및 UI 점검 기록

- 비공개 사이트 버전 81~87의 배포 성공과 앱 버전 v1.13.18~24를 확인했습니다.
- 별빛 임무, 도감 필터, 별 상세보기, 아이콘 규격과 모바일 접근성 변경을 관련 문서에 반영했습니다.
- Chrome 320px·390px에서 모바일 버튼 크기, 자리 표시, 도감 수치, 팝업 포커스 복원을 검증했습니다. 소스 자동 테스트 123개가 통과했습니다. iPhone Safari 실기기 검증은 미확인입니다.

## 2026-11-19 · v1.13.17까지 배포 이력과 UI 가이드 갱신

- 사이트 버전 76~80번의 배포 성공을 확인했습니다. 비공개 테스트 최신 버전은 v1.13.17, 공개 게임 저장소와 Pages는 v1.13.12입니다.
- PC 팝업 너비, 이야기 첫 읽기 모션과 목차, 설정과 조합·탐사 폼, 스크롤·단일 선택·알림·도움말을 기록했습니다.
- 배포용 ZIP의 압축 무결성과 정적 파일 경로를 확인했습니다. 최신 [버전 파일](../raw/v1.13.17/VERSION.json)과 [디자인 가이드](../raw/v1.13.17/COLOR-TOKENS.md)를 보관했습니다.

## 2026-11-19 · v1.13.12까지 배포 이력 갱신

- 비공개 사이트 56~75번의 성공 상태와 소스 버전을 확인했습니다. 최신 v1.13.12는 21:16 KST에 배포됐습니다.
- 공개 저장소 `main`과 공개 GitHub Pages에서 각각 v1.11.0을 확인했습니다.
- 글래스 UI, 블루 색상, 행성 윤곽, 자유 배치, 탄생 버튼 위치를 기록하고 v1.13.12 원본 자료를 추가했습니다.

## 2026-11-19 · v1.9.4 기준 배포 이력과 구현 업데이트

- 비공개 사이트의 성공 배포 55건을 확인해 [배포 이력](release-history.md)에 기록했습니다. 최신 버전은 v1.9.4입니다.
- 공개 게임 저장소의 v1.7.1 버전 파일과 GitHub Pages용 v1.9.4 ZIP 생성 기록을 [저장과 배포](save-release.md)에 반영했습니다.
- 가구 20종·최대 Lv.10, 별 50종과 이야기 250편, 외곽 관측소 및 파견 경로 명칭을 주제별로 갱신했습니다.
- v1.5.1~v1.9.4 릴리스 노트 발췌와 색상·글자 크기 토큰 문서를 출처에 추가했습니다. 기존 원본은 보존했습니다.

## 2026-11-18 · 초기 구성

- 사용자가 지정한 crazyjamy/lmmwiki 저장소가 비어 있음을 확인했습니다.
- 작고 소중한 먼지 키우기를 위키 주제로 구성했습니다.
- 기존 기획 README와 v1.4.1 ZIP을 원본 그대로 보관하고, ZIP 내부 파일을 변경 없이 풀어 코드 근거로 연결했습니다.
- 이번 사용자 메시지 발췌와 별도 대화 요약에서 전달된 가구 확장 요청을 출처 유형별로 보관했습니다.
- 게임 개요, 먼지 수집·성장, 방·가구, 재화·모험, 저장·배포, 확인할 사항을 작성했습니다.
- 과거 기획과 코드의 성장 방식·재화 사용 차이를 기록했습니다.
- 가구 20종·10단계 확장은 변경 요청으로 남기고 v1.4.1의 10종·5단계와 구분했습니다.
- 목차·자료 목록·위키 관리 규칙을 추가했습니다.
- 원본 체크섬, 압축 해제본의 바이트 일치, 문서 내부 링크, 코드 데이터 개수와 문서 수치를 확인했습니다.
- 브라우저 플레이와 현재 게임 사이트의 배포 상태는 검증하지 않았습니다.

이 기록의 날짜는 위키에 자료를 반영한 날짜입니다. 원본 자료의 작성·배포 날짜를 뜻하지 않습니다.
GitHub 업로드의 완료 여부는 실제 원격 커밋과 실행 결과 보고를 기준으로 판단합니다.
